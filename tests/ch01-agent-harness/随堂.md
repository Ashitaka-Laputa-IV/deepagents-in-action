### 判断题

1. Runtime、Framework、Harness 三者是互相替代的关系，只能选择其一。
2. LangChain 1.0 构建在 LangGraph 之上。
3. Claude Agent SDK 绑定 Claude 系列模型。
4. Codex SDK 仅支持 TypeScript 语言。
5. Deep Agents 是模型无关的，支持 Anthropic、OpenAI、Google、开源等 100+ 模型。
6. Deep Agents 的"文件系统"只能是本地磁盘。
