### 单选题

1. 在 LangChain 技术栈中，Agent 开发被划分为哪三个层次？B
   - A. Runtime → Harness → Framework
   - B. Runtime → Framework → Harness
   - C. Framework → Runtime → Harness
   - D. Harness → Framework → Runtime

   > 批阅：✓ 解析：三层自底向上为 Runtime → Framework → Harness。

2. 底层 Agent Runtime（运行时层）的代表实现是？C
   - A. LangChain
   - B. Deep Agents
   - C. LangGraph
   - D. CrewAI

   > 批阅：✓ 解析：底层运行时（Runtime）的代表实现是 LangGraph。

3. Agent Runtime 解决的核心问题是？B
   - A. 如何让 Agent 快速上手
   - B. 如何让 Agent 可靠地运行

   - D. 如何给 Agent 预置工具

   > 批阅：✓ 解析：Runtime 解决"Agent 怎么可靠地运行"。

### 简答题

1. 用一句话说明 Agent Harness 与 Runtime、Framework 的关系。
   runtime是底层, 是基础, 是底层实现,
   framework是对底层的封装, runtime的抽象
   harness是基于framework搭建的开箱即用的agent

   > 批阅：✓（基本达意，但表述可更精确）。参考要点：Agent Harness（Deep Agents）建立在 Runtime 和 Framework 之上——LangGraph 是底层运行时，LangChain 在其上提供更高层抽象，Deep Agents 在两者之上提供开箱即用的预置 Agent 能力，三者自底向上层层构建，非替代关系。

2. 简述"虚拟文件系统可插拔"的含义。
   虚拟文件系统插件化, 可以随意更改

   > 批阅：✓（方向正确，建议补充具体后端）。参考要点：文件操作被抽象为统一接口，后端可按需插拔——可为内存（开发调试）、本地磁盘（真实文件）、持久化数据库（跨会话记忆）、远程沙箱（安全执行代码），甚至可混合使用，不同路径路由到不同后端。
