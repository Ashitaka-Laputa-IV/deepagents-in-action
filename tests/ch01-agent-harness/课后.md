# 【第 1 章：从 Agent Framework 到 Agent Harness】课后练习

## 课后练习

题目跨知识点、设情境、做对比，考查"能否运用/迁移"。

### 单选题

1. 某团队需要最大灵活性、精细控制底层执行引擎，选择直接使用 LangGraph 构建长期运行的 Agent，此时他们工作在哪一层？
   - A. Runtime（底层）
   - B. Framework（中间层）
   - C. Harness（上层）
   - D. 无法确定

2. 某企业级项目要求模型无关、可随时切换厂商，且需要跨会话持久化记忆，最适合的选择是？
   - A. LangGraph
   - B. Deep Agents
   - C. Claude Agent SDK
   - D. Codex SDK

3. 某团队全面使用 Claude 模型，需要与 Claude 深度集成并拦截、控制 Agent 行为，应优先选择？
   - A. Deep Agents
   - B. Codex SDK
   - C. Claude Agent SDK
   - D. LangChain

4. 某场景需要 OS 级别的沙箱模式（`read-only`、`workspace-write`、`danger-full-access`）以及内置 MCP Server 模式，应选择？
   - A. Deep Agents
   - B. Claude Agent SDK
   - C. Codex SDK
   - D. LangGraph

5. 某 Agent 希望在本地运行，但把代码执行这类特定操作发送到远程沙箱中执行，这对应 Deep Agents 的哪个独有特性？
   - A. 长期记忆
   - B. Sandbox-as-Tool 模式
   - C. 虚拟文件系统
   - D. 流式输出

6. 一个 Agent 处理一个含 20 个文件、共 50000 tokens 的仓库，且只有部分文件当前步骤需要。按 Context Engineering 理念，正确处理方式是？
   - A. 把 20 个文件完整内容一次性塞进 prompt
   - B. 用 `read_file` 按需读取，大文件用 `offset`/`limit` 只读需要的部分
   - C. 压缩全部文件后一次性塞入
   - D. 完全不读取文件，靠 LLM 记忆

### 多选题

1. 以下哪些场景适合选择 Deep Agents？（多选）
   - A. 需要模型灵活性，不锁定任何厂商
   - B. 需要跨会话、跨线程的长期记忆
   - C. 需要完整的生产部署和可观测性方案（搭配 LangSmith）
   - D. 只需要快速写一个简单的单步问答

2. 要构建复杂多步骤、自主性较高的 Agent，可选择在哪些层次工作？（多选）
   - A. 直接用 LangGraph（Runtime）
   - B. 用 LangChain（Framework）
   - C. 用 Deep Agents（Harness）
   - D. 以上均可，取决于需求

3. Deep Agents 相对 Claude Agent SDK 和 Codex SDK，在架构层面的差异体现在？（多选）
   - A. 模型无关
   - B. 支持长期记忆（Memory Store）
   - C. 虚拟文件系统 + 可插拔后端
   - D. Sandbox-as-Tool 模式

4. 关于虚拟文件系统的可插拔后端，下列哪些说法正确？（多选）
   - A. 后端可以是内存、磁盘、数据库或沙箱
   - B. 可以混合使用，不同路径路由到不同后端
   - C. 后端一旦选定不可更改
   - D. 这是 Deep Agents 独有的设计

### 判断题

1. Claude Agent SDK 支持跨会话、跨线程的长期记忆。
2. Deep Agents 采用 Sandbox-as-Tool 模式，Agent 在本地运行但可把特定操作发送到远程沙箱。
3. 把文件信息全部塞进 prompt 可以彻底解决上下文溢出问题。
4. Deep Agents 的长期记忆能力是 Claude Agent SDK 和 Codex SDK 都不支持的。

3. 在处理大型仓库时，Deep Agents 通过 `grep` 或______进行搜索，而非读取全部文件。
4. LangGraph 解决的是 Agent"怎么______地运行"的问题，对应持久化执行、流式输出等能力。

   - A. Deep Agents

   - C. Codex SDK

### 排序题

1. 按 Context Engineering 理念，处理一个大型项目的合理顺序是？
   - ① 需要时用 `read_file` 按需读取，大文件仅读需要的部分
   - ② 需要搜索时调用 `grep` 或 `glob` 查找
   - ③ 记录中间结果时调用 `write_file` 写到文件
   - ④ 上下文只保留当前步骤真正需要的信息

### 案例分析题

1. 某公司要构建一个企业级 AI 编程助手，需求如下：
   - 不锁定任何模型厂商，希望能灵活切换
   - 需要跨会话记住用户的偏好
   - 需要安全地在远程沙箱中执行代码，同时 Agent 本身在本地运行
   - 需要完整的生产部署与可观测性方案
   请判断应选择哪个 Harness，并说明各项需求分别对应其哪些能力。

2. 结合三层架构（Runtime / Framework / Harness），为"需要精细控制、长期运行、且需要快速开发上手"的团队，设计一个合理的分层选型策略并说明理由。
