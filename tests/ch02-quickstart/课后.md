# 【第 2 章：快速上手 — 5 分钟构建你的第一个 Deep Agent】课后练习

## 课后练习

题目跨知识点、设情境、做对比，考查"能否运用/迁移"。

### 单选题

1. 你的团队在国内无代理环境，希望用 OpenAI 兼容接口接入免费模型来学习和实验，最适合的模型提供商配置是？
   - A. 直连 Anthropic 官方 API
   - B. 使用硅基流动，配置 `SILICONFLOW_API_KEY` 和 `ChatOpenAI`
   - C. 直连 OpenAI 官方 API
   - D. 本地部署一个 7B 模型且不配 API Key

2. 某复杂任务需要"多子 Agent 编排"，你已配置了默认的 `Qwen/Qwen2.5-7B-Instruct`，合理做法是？
   - A. 保持默认模型不变
   - B. 通过 `MODEL_NAME` 环境变量改用 `zai-org/GLM-5.2` 等更强模型
   - C. 增大 `system_prompt` 的长度
   - D. 增加 tools 的数量

3. 你写了一个工具 `def get_stock(symbol: str, market: str = "US") -> dict:`，若用户只需查美股，Agent 最可能的行为是？
   - A. 必须同时提供 `symbol` 和 `market`
   - B. 只需提供 `symbol`，`market` 用默认值
   - C. 无法调用该工具
   - D. 需要重写函数

4. 想从硅基流动切换到 DeepSeek 平台，你的 `ChatOpenAI` 配置中需要改变的是？
   - A. `model`、`base_url`、`api_key`
   - B. 换成 `ChatAnthropic`
   - C. 换成 `provider:model_name` 字符串并配 `OPENAI_API_KEY`
   - D. 重新安装 deepagents

5. 你希望 Agent 能完成"读取源码 → 拆解任务 → 多步搜索 → 写出报告"，且只传入了一个 `internet_search` 工具。Agent 能完成的原因是？
   - A. 你需要手动配置文件系统和规划工具
   - B. Deep Agent 自动附带文件系统、任务规划、子 Agent 等内置能力
   - C. `internet_search` 本身包含全部能力
   - D. `system_prompt` 会自动注入这些工具

6. 当 Agent 行为不符合预期时，最合适的排查方式是？
   - A. 打印所有工具的源码
   - B. 开启 LangSmith 追踪，查看 Trace 面板中的决策链路与工具调用
   - C. 随机修改 `system_prompt`
   - D. 增加模型上下文窗口

7. 你写了一个 `convert_currency` 工具，`to_currency` 设默认值 `"CNY"`，但忘记写 docstring。Agent 最可能遇到的困难是？
   - A. 无法识别参数类型
   - B. 不知道何时该使用这个工具
   - C. 默认值失效
   - D. 返回类型错误

### 判断题

1. 配置好 `LANGSMITH_TRACING` 和 `LANGSMITH_API_KEY` 环境变量后，无需修改代码即可自动上传运行记录。
2. Deep Agents 的 `model` 参数只能传 `ChatOpenAI` 模型实例。
3. 系统提示词中显式加入工具使用说明是必须的，否则 Agent 无法理解工具。
4. Tavily 当前免费计划每月包含 1,000 Credits。
