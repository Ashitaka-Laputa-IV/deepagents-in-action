# 【第 2 章：快速上手 — 5 分钟构建你的第一个 Deep Agent】课后练习

## 课后练习

题目跨知识点、设情境、做对比，考查"能否运用/迁移"。

### 单选题

1. 你的团队在国内无代理环境，希望用 OpenAI 兼容接口接入免费模型来学习和实验，最适合的模型提供商配置是？C
   - A. 直连 Anthropic 官方 API
   - B. 使用硅基流动，配置 `SILICONFLOW_API_KEY` 和 `ChatOpenAI`
   - C. 直连 OpenAI 官方 API
   - D. 本地部署一个 7B 模型且不配 API Key

   > 批阅：✗ 正确答案应为 B（硅基流动）。解析：题干前提是"国内**无代理**环境"，直连 OpenAI 官方 API 在国内无代理下无法访问，因此应选国内直连、兼容 OpenAI 接口的硅基流动。（补充说明：本题考"选哪家平台"本身也偏死记，属应优化的一类）

2. 某复杂任务需要"多子 Agent 编排"，你已配置了默认的 `Qwen/Qwen2.5-7B-Instruct`，合理做法是？B
   - A. 保持默认模型不变
   - B. 通过 `MODEL_NAME` 环境变量改用 `zai-org/GLM-5.2` 等更强模型
   - C. 增大 `system_prompt` 的长度
   - D. 增加 tools 的数量

   > 批阅：✓ 解析：小模型在复杂编排场景跑不稳，应换更强模型使能力与复杂度匹配。

3. 你写了一个工具 `def get_stock(symbol: str, market: str = "US") -> dict:`，若用户只需查美股，Agent 最可能的行为是？B
   - A. 必须同时提供 `symbol` 和 `market`
   - B. 只需提供 `symbol`，`market` 用默认值
   - C. 无法调用该工具
   - D. 需要重写函数

   > 批阅：✓ 解析：默认值标记参数可选，Agent 只填必填项 `symbol`。

4. 想从硅基流动切换到 DeepSeek 平台，你的 `ChatOpenAI` 配置中需要改变的是？A
   - A. `model`、`base_url`、`api_key`
   - B. 换成 `ChatAnthropic`
   - C. 换成 `provider:model_name` 字符串并配 `OPENAI_API_KEY`
   - D. 重新安装 deepagents

   > 批阅：✓ 解析：切平台本质是改三类连接信息：模型标识、服务地址（`base_url`）、凭证（`api_key`）。

5. 你希望 Agent 能完成"读取源码 → 拆解任务 → 多步搜索 → 写出报告"，且只传入了一个 `internet_search` 工具。Agent 能完成的原因是？B
   - A. 你需要手动配置文件系统和规划工具
   - B. Deep Agent 自动附带文件系统、任务规划、子 Agent 等内置能力
   - C. `internet_search` 本身包含全部能力
   - D. `system_prompt` 会自动注入这些工具

   > 批阅：✓ 解析：这正是 Harness 的价值——文件系统、任务规划、子 Agent 等内置能力无需手动配置。

6. 当 Agent 行为不符合预期时，最合适的排查方式是？B
   - A. 打印所有工具的源码
   - B. 开启 LangSmith 追踪，查看 Trace 面板中的决策链路与工具调用
   - C. 随机修改 `system_prompt`
   - D. 增加模型上下文窗口

   > 批阅：✓ 解析：可观测性平台能呈现完整决策链路，是定位问题的首选。

7. 你写了一个 `convert_currency` 工具，`to_currency` 设默认值 `"CNY"`，但忘记写 docstring。Agent 最可能遇到的困难是？B
   - A. 无法识别参数类型
   - B. 不知道何时该使用这个工具
   - C. 默认值失效
   - D. 返回类型错误

   > 批阅：✓ 解析：docstring 告知工具用途与调用时机，缺失时 Agent 不知何时用。
