## 课后练习

题目跨知识点、设情境、做对比，考查"能否运用/迁移"。按本章主题，全部考查理解、原理、应用与对比，不出"记名字/记数字"类的死记题。

### 单选题

1. 团队在国内无代理环境，想在兼容 OpenAI 接口的模型上学习 Agent。从"接口适配"的角度看，最合理的接入思路是？

   - C. 直连 Anthropic 官方 API
   - D. 本地硬跑一个模型且不配任何凭证

2. 默认轻量模型在"多子 Agent 编排"这类复杂流程中跑不稳。合理的应对思路是？

   - C. 增大 `system_prompt` 的长度
   - D. 增加 `tools` 的数量

3. 你写了一个工具 `def get_stock(symbol: str, market: str = "US") -> dict:`，若用户只需查美股，Agent 最可能的行为是？

4. 从一家兼容平台切换到另一家兼容平台（都走 OpenAI 接口）时，本质上是更换哪类信息？

5. 你希望 Agent 能完成"读取源码 → 拆解任务 → 多步搜索 → 写出报告"，且只传入了一个搜索工具。Agent 仍能完成的原因是？

6. 当 Agent 行为不符合预期时，最合适的排查方式是？

7. 你写了一个 `convert_currency` 工具，`to_currency` 设了默认值，但忘记写 docstring。Agent 最可能遇到的困难是？

### 判断题

1. 配置好可观测性环境变量后，无需修改代码即可自动记录运行过程。
2. Deep Agents 的 `model` 参数只能传模型实例，不能传 `provider:model_name` 字符串。
3. 系统提示词中显式加入工具使用说明是必须的，否则 Agent 无法理解工具。
4. 把搜索结果写入虚拟文件系统、按需读取，比一次性全部塞进 prompt 更能避免上下文溢出。

### 排序题

1. 请将"构建研究助手"的关键阶段排序（逻辑顺序，非唯一）：
   - ① 运行并查看结果
   - ② 准备搜索能力（定义 / 接入搜索工具）
