### 判断题

1. Deep Agents 只需一个普通 Python 函数加类型标注和 docstring 即可作为一个工具。
2. `agent.invoke()` 的输入是包含 `messages` 的字典，输出也是字典。
3. 硅基流动只支持 OpenAI 兼容接口，不支持 Anthropic 兼容接口。
4. 配置好 LangSmith 环境变量后，需要修改代码才能把运行记录上传到 LangSmith。
5. 小模型（如 7B）在复杂任务规划场景往往能稳定跑通完整流程。
6. Deep Agents 的 `model` 参数既可以传模型实例，也可以传 `provider:model_name` 字符串。
