# 【第 2 章：快速上手 — 5 分钟构建你的第一个 Deep Agent】随堂测验

## 随堂测验

题目直接对应单个知识点，考查"是否理解/能应用"。

### 单选题

1. Deep Agents 为何能用"一个普通的 Python 函数"直接作为工具？
   - A. Agent 通过函数的签名（参数名和类型标注）和 docstring 来理解工具能做什么
   - B. Python 内置了工具注册与发现机制
   - C. 所有函数都会自动暴露为全局工具
   - D. 只有无参函数才允许被用作工具

2. 你写了一个工具但忘记写 docstring，Agent 最可能遇到的问题是什么？
   - A. 不知道何时该使用这个工具
   - B. 函数无法通过语法检查
   - C. 参数类型标注自动失效
   - D. 工具不会被加载

3. 为工具参数设置默认值的意义在于？
   - A. 标记该参数可选，Agent 只需填必填参数，减少出错
   - B. 让函数执行得更快
   - C. 让函数结果固定不变
   - D. 让参数无法被覆盖

4. `agent.invoke()` 的输入与输出都采用"包含 `messages` 的字典"结构，主要原因是？
   - A. 遵循标准消息协议，便于在完整对话历史中追踪 Agent 的上下文
   - B. 字典比列表更节省内存
   - C. 这是终端输出的唯一合法格式
   - D. 只有字典才能被 JSON 序列化

5. 在计算器示例中，`calculate(expression: str)` 用字符串承接整个表达式，类型标注 `str` 的作用是？
   - A. 明确告知 Agent 应传入文本形式的表达式，而非拆成多个数字参数
   - B. 让计算执行得更快
   - C. 避免使用浮点数
   - D. 让结果必须是字符串

6. 研究助手把大量搜索结果用 `write_file` 写入虚拟文件系统，而不是一次性塞进 prompt，原因是？
   - A. 防止上下文窗口溢出，按需读取（Context Engineering 的核心思想）
   - B. 文件系统比内存更稳定
   - C. 让 Agent 无法直接访问结果
   - D. 这是 LangSmith 的强制要求

7. 国内模型平台普遍兼容 OpenAI 接口，因此你只需用 `ChatOpenAI` 并更换 `base_url` 就能接入不同平台。这体现的设计模式是？
   - A. 通过统一接口适配不同模型提供商
   - B. 每换一个平台都要重写整个 Agent
   - C. 只有 OpenAI 官方模型才能被使用
   - D. `base_url` 只对某一家平台有效

8. 小模型（如 7B）在"多子 Agent 编排"等复杂场景往往无法稳定跑通完整流程，因此建议改用能力更强的模型。这说明？
   - A. 模型能力需要与任务复杂度相匹配
   - B. 小模型在任何场景都无法使用
   - C. 模型越大就一定越好，无需权衡
   - D. 模型选择与任务复杂度无关

9. 关于系统提示词（System Prompt），下列说法正确的是？
   - A. 它定义了 Agent 的角色、能力和工作方式
   - B. 它必须包含所有工具的源码
   - C. 它决定了模型可以调用哪些硬件
   - D. 没有它 Agent 就无法运行

10. OpenAI 兼容接口（`/chat/completions`）与 Anthropic 兼容接口（`/messages`）的本质区别在于？
    - A. 两者是不同的消息协议标准，使用方需按接口格式接入
    - B. 前者只支持文本，后者只支持图片
    - C. 前者免费，后者收费
    - D. 两者完全等价，无任何差异

### 多选题

1. 工具三要素（参数类型标注、Docstring、默认值）分别起什么作用？（多选）
   - A. 参数类型标注：告知 Agent 每个参数应传的类型，避免传错
   - B. Docstring：告知 Agent 工具的用途和调用时机
   - C. 默认值：标记参数可选，减少必填项
   - D. 三者缺一不可，共同决定 Agent 能否准确调用工具

2. 关于"一个普通 Python 函数即一个工具"，以下说法正确的有？（多选）
   - A. Agent 通过函数签名和 docstring 理解工具的用法
   - B. 清晰的 docstring 能让 Agent 用得更准确
   - C. 参数类型标注可降低 Agent 传错类型的概率
   - D. 默认值可减少必填参数、降低出错概率

3. Deep Agent 除了你传入的 `tools`，还会自动附带一系列内置能力，这体现了 Harness 的价值。这些内置能力包括？（多选）
   - A. 文件系统操作
   - B. 任务规划
   - C. 子 Agent 委派
   - D. 以上都不需要你手动配置

4. 关于接入模型的三种方式，以下说法正确的有？（多选）
   - A. `ChatOpenAI` + `base_url` 适合接入国内兼容 OpenAI 接口的平台
   - B. `ChatAnthropic` 适合偏好 Anthropic 消息格式的场景
   - C. `provider:model_name` 字符串适合原生平台直连
   - D. 三种方式都必须经由第三方中转平台

5. 关于 `agent.invoke()`，以下说法正确的有？（多选）
   - A. 输入是包含 `messages` 的字典
   - B. 输出也是一个字典
   - C. `result["messages"]` 包含完整对话历史
   - D. 最后一条消息就是 Agent 的最终回复

### 判断题

1. 系统提示词中显式加入工具使用说明是必须的，否则 Agent 无法使用工具。
2. 配置好 LangSmith 追踪环境变量后，需要修改代码才能上传运行记录。
3. Deep Agents 的 `model` 参数既可以传模型实例，也可以传 `provider:model_name` 字符串。
4. 一个带类型标注和 docstring 的普通 Python 函数，就能被 Deep Agent 用作工具。
5. 只依赖默认的小模型就能稳定跑通所有复杂多步骤任务。

### 排序题

1. 请将"`agent.invoke()` 背后 Deep Agent 的执行流程"排序：
   - ① 综合报告——从文件系统读取整理好的信息，撰写最终报告
   - ② 管理上下文——调用 `write_file` 将搜索结果写入虚拟文件系统
   - ③ 规划任务——调用 `write_todos` 把任务拆解为子步骤
   - ④ 委派子任务（如需要）——调用 `task` 委派给子 Agent
   - ⑤ 搜索信息——调用 `internet_search` 执行多次网络搜索
