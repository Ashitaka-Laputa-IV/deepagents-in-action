# 【第 2 章：快速上手 — 5 分钟构建你的第一个 Deep Agent】随堂测验

## 随堂测验

题目直接对应单个知识点，考查"是否理解/能应用"。

### 单选题

1. Deep Agents 为何能用"一个普通的 Python 函数"直接作为工具？A
   - A. Agent 通过函数的签名（参数名和类型标注）和 docstring 来理解工具能做什么
   - B. Python 内置了工具注册与发现机制
   - C. 所有函数都会自动暴露为全局工具
   - D. 只有无参函数才允许被用作工具

   > 批阅：✓ 解析：Agent 无需额外注册，直接通过函数签名（参数名+类型标注）和 docstring 理解工具的用途与调用方式。

2. 你写了一个工具但忘记写 docstring，Agent 最可能遇到的问题是什么？A
   - A. 不知道何时该使用这个工具
   - B. 函数无法通过语法检查
   - C. 参数类型标注自动失效
   - D. 工具不会被加载

   > 批阅：✓ 解析：docstring 告知 Agent 工具的用途，缺失时 Agent 不知道该在何时调用。

3. 为工具参数设置默认值的意义在于？A
   - A. 标记该参数可选，Agent 只需填必填参数，减少出错
   - B. 让函数执行得更快
   - C. 让函数结果固定不变
   - D. 让参数无法被覆盖

   > 批阅：✓ 解析：默认值标记参数可选，Agent 只填必需参数即可，降低出错概率。

4. `agent.invoke()` 的输入与输出都采用"包含 `messages` 的字典"结构，主要原因是？A
   - A. 遵循标准消息协议，便于在完整对话历史中追踪 Agent 的上下文
   - B. 字典比列表更节省内存
   - C. 这是终端输出的唯一合法格式
   - D. 只有字典才能被 JSON 序列化

   > 批阅：✓ 解析：采用标准消息格式，`result["messages"]` 保留完整对话历史，便于上下文追踪。

5. 在计算器示例中，`calculate(expression: str)` 用字符串承接整个表达式，类型标注 `str` 的作用是？A
   - A. 明确告知 Agent 应传入文本形式的表达式，而非拆成多个数字参数
   - B. 让计算执行得更快
   - C. 避免使用浮点数
   - D. 让结果必须是字符串

   > 批阅：✓ 解析：类型标注决定输入形态——告知 Agent 传整段文本表达式，而非拆成多个数字参数。

6. 研究助手把大量搜索结果用 `write_file` 写入虚拟文件系统，而不是一次性塞进 prompt，原因是？A
   - A. 防止上下文窗口溢出，按需读取（Context Engineering 的核心思想）

   > 批阅：✓ 解析：对应第 1 章的 Context Engineering——写入文件、按需读取，避免上下文溢出。

7. 国内模型平台普遍兼容 OpenAI 接口，因此你只需用 `ChatOpenAI` 并更换 `base_url` 就能接入不同平台。这体现的设计模式是？A
   - A. 通过统一接口适配不同模型提供商
